    How the first admin gets in

    1. 1The app is deployed with a secret setup token in its server settings.
    2. 2The deployer gives the token to the first admin, in person or by phone.
    3. 3The admin enters the token, name, mobile, email and password here.
    4. 4The admin scans a QR code in Google or Microsoft Authenticator and saves 10 backup codes.
    5. 5Setup closes for good. The admin adds a second admin and all users from the dashboard.
